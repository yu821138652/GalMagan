## GalMagan 是什么

GalMagan 使用 Android 无障碍服务读取当前聊天界面可见的消息，并把对话整理成情境分析、回复策略和候选回复。它适用于希望理解聊天上下文、减少说话人混淆，并让候选回复更贴近个人表达习惯的场景。

项目目前主要面向微信和小红书。不同应用、系统版本和页面布局提供的无障碍信息不同，实际读取效果可能有差异；目前明确完成的微信真机验证范围见上方稳定版说明。

## 功能

| 能力 | 说明 |
| --- | --- |
| 情境与风险分析 | 依次分析对话、评估 0–9 级风险、形成回复策略，再生成并检查候选回复。 |
| 回复方向 | 可选择默认、安抚与化解冲突、自然延续话题或增进好感。 |
| 本次补充 | 可补充事实或表达偏好，并在本轮分析中继续调整；补充不会写入聊天历史。 |
| 联系人知识库 | 记录联系人背景、全局说话风格，以及面向特定联系人的风格。 |
| 历史记录 | 可预加载和自动更新聊天记录，按联系人及聊天环境保存；分析时合并同一联系人的跨环境历史。 |
| 人工把关 | 候选只会填入聊天输入框，不会自动发送；最终内容由你检查并决定。 |
| 故障诊断 | 提供分析停止、界面刷新、识别状态和可复制的错误反馈。 |

## 下载与首次启动

1. 下载 [GalMagan 2.0.8 APK](https://github.com/yu821138652/GalMagan/blob/v2.0.8/apk/GalMagan-2.0.8-debug.apk)，并按需核对 [SHA-256 校验值](apk/GalMagan-2.0.8-debug.apk.sha256)。这是 Debug APK。
2. 安装并打开 GalMagan，在首页开启无障碍服务和“显示在其他应用上层”权限。
3. 荣耀手机建议允许 GalMagan 自启动和后台运行，避免系统省电策略冻结无障碍服务或悬浮窗。
4. 进入设置配置模型接口，保存后回到微信或小红书。

## 模型配置

两种模式都必须配置“通用模型接口”。进入“设置 → 接口”，填入服务商提供的 Base URL、API 密钥和模型 ID。可选 OpenRouter、DeepSeek 官方、通义兼容接口，也可选“自定义”。自定义接口需兼容 OpenAI Chat Completions；应用会在 Base URL 后补上 `/chat/completions`。新安装默认模型 ID 为 `gpt-6-luna`，是否可用取决于服务商是否提供该模型。

### 1. Jev + 通用模型

在“分析模式”选择“通用模型 + Jev 辅助（可选）”，并配置上面的通用模型接口，再展开“Jev 辅助接口”：

1. 选择 OpenRouter、TypeSafe 直连或自定义，并填写该服务对应的密钥和模型。
2. OpenRouter 和 TypeSafe 会按所选服务拼接接口路径；自定义模式要填写完整的 Jev POST URL。
3. 分别使用“测试判断”和通用模型卡片中的“测试连接”，确认两个接口可用，再点“测试完整分析”检查整条流程。
4. 点击页面底部“保存全部设置”。

Jev 只提供风险参考；情境理解、回复策略、候选生成和候选检查仍由通用模型完成。Jev 未配置、余额不足或请求失败时，通用模型仍会继续分析。

### 2. 双层通用模型（无需 Jev）

在应用的“分析模式”选择“通用模型（无需 Jev）”，只配置通用模型接口并保存。这里的“双层”指通用模型承担分析与回复两部分工作：应用使用同一 Base URL、密钥和模型，依次请求“情境与风险分析、回复策略 → 候选生成 → 候选检查与修正”。当前版本不需要 Jev，也不提供两套通用模型分别填写的配置项。

建议先点“测试连接”，再点“测试完整分析”。前者只检查接口能否返回文本；后者会实际运行完整多阶段流程，可能产生多次模型请求并消耗服务额度。

“视觉接口”与以上两种分析模式分开，常规文本分析不需要配置。当前聊天截图 OCR 使用本地 ML Kit；设置里的视觉接口用于单独测试远程视觉模型，不是聊天识别的必需项。未配置视觉接口也可正常分析文字聊天。

## 详细使用方式

### 建立联系人与历史

1. 在“知识库与联系人”中添加联系人，补充关系描述和背景信息。联系人风格记录的是“面向此人”的表达方式；全局风格供默认对象使用。
2. 首次补齐旧聊天时，在聊天软件打开该联系人的聊天，并回到最新消息位置。长按 GalMagan 悬浮球菜单，点“预加载历史记录”，依次选择联系人和聊天环境，再开始预加载。
3. 按界面提示翻阅历史。悬浮窗会显示采集进度、新增和重复数量；需要结束时点停止并保存。完成后可在联系人历史中检查内容和顺序。
4. 需要后续自动记录时，在“设置 → 分析”开启“记录聊天历史”和“自动更新联系人历史”。历史按联系人与聊天环境分别保存；分析时会合并同一联系人的跨环境历史。自动更新针对最新消息，补采较早历史请使用预加载。

### 分析当前聊天

1. 在微信或小红书进入具体聊天，确认当前显示的是最新消息。若正在查看旧消息，先回到聊天底部。
2. 打开悬浮窗，选择对应知识库联系人；临时分析未建档对象时选择“默认（不使用联系人历史）”。默认模式只使用当前识别内容和全局设置，不读取或保存其他联系人的历史。
3. 选择聊天方向：“默认”“安抚与化解冲突”“自然延续话题”或“增进好感”，再点“分析当前对话”。分析结果会依次显示情境与风险、回复策略和候选回复；“仍缺失的背景”默认折叠，“查看当前注入上下文”可展开本轮实际使用的消息。
4. 如果需要纠正事实或调整表达，在“补充说明／调整方向”中输入说明并提交，可继续补充多轮；这些内容只用于本次分析，不会写入真实聊天、历史记录或风格档案。点清除入口可重置本次调整。
5. 点选一条候选会将内容填入聊天输入框，不会自动发送。发送前请自行检查事实、语气和接收对象。

### 检查历史与识别问题

- 在知识库联系人中选择具体聊天环境查看历史；可长按编辑消息、修正发送方或多选删除。分析前可检查历史最新一条，确认是否需要预加载补全。
- 小红书优先读取无障碍消息节点，节点没有正文时可能回退 OCR；识别结果仍应检查发送方和内容。
- 微信自动截图关闭，正常读取依靠无障碍节点。必要时可在悬浮窗菜单点“截屏识别一次”；截图受系统或微信限制时，不要反复触发。
- 分析卡片无响应时可点悬浮窗设置按钮左侧的刷新按钮。发生错误时在应用内复制诊断信息，反馈时先隐藏聊天正文、联系人资料和密钥。

## 常见问题

**为什么需要开启无障碍权限？**

GalMagan 通过 Android 无障碍服务读取当前聊天页面提供的可见文本，用于识别说话人和整理上下文。它不读取聊天应用的内部数据库。

**聊天内容会发送到哪里？**

分析上下文会发送到设置中配置的模型服务。请使用你信任的服务，并查看其数据处理政策；API 密钥由你在应用内配置。

**为什么有时读不到消息？**

聊天应用和系统版本可能提供不同的无障碍节点。当前确认的微信验证组合是荣耀 Magic7、Android 16、微信 8.0.80；其他设备或版本需要单独验证。识别失败时，可在应用内复制诊断信息用于排查。

**候选回复会自动发出去吗？**

不会。候选只会填入输入框，发送前由你检查并操作。

## 隐私与权限

- 无障碍权限用于读取当前聊天界面可见内容。应用不读取微信或小红书的内部数据库，也不修改这些应用。
- 联系人资料、历史记录和风格档案保存在 GalMagan 的应用私有目录中。
- 分析时，对话上下文会发送到你配置的模型服务。请先了解该服务商的数据处理规则；项目不会内置你的 API 密钥。
- 候选回复不会自动发送。应用不会把“候选已生成”当作用户同意发送。
- 微信自动截图关闭；是否发起手动截图由用户操作。

需要 JDK 17、Android SDK 35 和 Gradle Wrapper 所需依赖：

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest
```

Debug APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。稳定版 APK 与校验文件位于 `apk/`；其他构建产物和缓存不纳入版本控制。最近一次稳定版验证见 [2.0.8 归档记录](docs/releases/2.0.8.md)。
