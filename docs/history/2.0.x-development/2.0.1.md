# 2.0.1 测试说明

本版继续基于 `feature/general-model-2.0` 开发，版本号 2.0.1，版本代码 39。`v1.6.4` 回退归档保持不变，不发布 GitHub Release。

## 悬浮窗

- 读取、分析、生成和评审过程中均提供“停止分析”。停止后旧回调不能覆盖界面或继续填入回复。
- 设置按钮左侧的刷新图标用于停止当前任务、清除本次分析与调整、刷新节点缓存并重建悬浮窗。配置、本地历史及风格不清空，所选联系人保留。
- “已表达的事实”不再显示，事实仍参与分析及后续生成。“仍缺少的背景”默认折叠，点击可查看。
- 输入补充说明时保持结果和编辑器；提交时复核聊天是否更新。输入法仅遮住较早消息时，不据此认定聊天已经变更。

## 历史合并

每个联系人、每个环境内部按从旧到新保存。分析依然综合同一联系人的跨环境历史，没有原始时间时不推断跨软件的真实先后。

最新页追加新尾部；即使长时间未打开导致两屏无重叠，也可以追加。预加载向上翻页时，用上一页作为位置锚点，把新增内容插入对应位置，支持从最新页向前补齐已有历史中间的缺口。无重叠时显示提示，等待保留部分重叠的页面，不猜测顺序。

自动记录只写最新位置，串行保存，避免线程完成顺序不同造成错位。重复判断以序列位置为依据，不按消息文本全局删除。编辑和删除后的原始屏幕仍用于防止自动更新还原手工修正。

旧版本已经写错的历史不会自动清理。连续重复且缺少原始时间、消息 ID 的内容，仍可能无法仅凭可见文本区分不同次发送；可在历史详情检查处理。

## 验证

执行 `:app:testDebugUnitTest :app:assembleDebug`。新增回归覆盖已有记录后的最新页追加、向前补齐缺口、多轮重叠采集、跨环境隔离、重复短语、可见范围扩大、手动删改保留及在途 HTTP 取消。

本轮结果：107 项通过、0 失败，1 项真实模型评估因未配置测试凭据而跳过。APK 已核对包名、2.0.1 版本号、版本代码 39 及原有调试签名。

带版本号的安装包保存于 `apk/GalMagan-2.0.1-debug.apk`，另在标准构建输出目录提供同名副本。`apk/` 中的版本文件不受下一轮构建输出清理影响，不进入 Git。

真机重点检查：打开和关闭补充输入法后界面是否保持；分析各阶段停止后能否立即重试；刷新后能否继续采集；有旧历史时从最新开始预加载，确认末尾最新消息没有移到前面。微信是否提供可读无障碍节点仍由实际运行情况决定，自动截图策略不变。
