# 1.6.0 历史稳定版

源码标签：[`v1.6.0`](https://github.com/yu821138652/GalMagan/tree/v1.6.0)。该版本是 GalMagan 最早保留的稳定基线之一，后续 `1.6.1` 至 `1.6.4` 的改动见 [1.6.4 归档记录](1.6.4.md)。

## 相较于前一应用版本 1.5.2

`1.5.2` 没有单独的 Git 标签；这里按应用版本记录对比。`1.6.0` 的主要变化是整理应用整体界面和交互入口：

- 首页加入 GalMagan 品牌图标、知识库与联系人的快捷入口，并整理权限状态卡片。
- 重做知识库、设置和联系人编辑页面的视觉层级，统一开关、输入框、卡片和按钮样式。
- 调整悬浮分析面板的内容层级、触控区域、候选回复卡片和识别状态提示。
- 将 GalMagan 图标应用到启动器，统一应用内外的品牌视觉。

这一版本侧重界面与品牌整理；按聊天环境隔离历史、预加载进度和历史批量编辑等能力是在 `1.6.1` 至 `1.6.4` 中逐步加入的。完整逐版本记录见根目录 [CHANGELOG.md](../../CHANGELOG.md)。

## 版本边界

本标签用于保留当时的应用基线。设备兼容性和权限行为以对应 Android 版本及聊天应用实际测试为准；不要将后续版本新增的功能视为 `1.6.0` 已具备。
