# 1.6.4 阶段归档

归档日期：2026-10-16。源码标签：`v1.6.4`。应用版本：`1.6.4`，版本代码：`37`。

本版本保存当前开发成果，作为下一阶段大改动的起点，不替换历史稳定标签 `v1.6.0`。

## 已保存功能

- 按联系人选择聊天对象，支持不使用联系人历史的默认模式。
- 预加载历史时选择联系人和聊天环境，显示采集进度并支持主动停止；自动更新按环境去重。
- 分析时合并同一联系人的跨环境历史，实际注入上下文可展开查看并标注来源。
- 小红书优先读取无障碍节点，仅在正文为空时使用 OCR；微信保留节点读取、缓存刷新和窗口诊断，关闭自动截图。
- 历史详情支持编辑正文与发送方、多选或全选删除，删改后保留浏览位置。
- 全局及面向联系人的说话风格档案支持主动合成与手动编辑。
- 悬浮窗显示分析结果与候选回复，候选回复可填入输入框，由用户决定是否发送。

## 已知问题与验证

- 小红书：维护者最新真机反馈可以使用。OCR 回退仍可能有文字和发送方识别误差。
- 微信：偶尔无法读取消息，曾出现总节点数为 1、其他计数为 0 的空节点树。刷新缓存和检查同应用窗口尚未完全解决此问题，当前不推断为截图限制所致。
- 微信自动截图关闭，显式手动“截屏识别一次”入口保留。
- 本地单元测试共 29 项，其中节点读取测试 20 项、历史存储测试 9 项，均通过。
- Debug APK 构建成功。界面交互未进行自动化真机测试，节点读取和截图能力受设备系统、权限与聊天应用版本影响。

## 安装包

[GitHub 归档发布页](https://github.com/yu821138652/GalMagan/releases/tag/v1.6.4) 提供以下附件：

- `GalMagan-1.6.4-debug.apk`：Android 11 及以上，`arm64-v8a`，应用标识 `com.jev.probe.custom`。
- `SHA256SUMS.txt`：安装包的 SHA-256 校验值。

归档使用本阶段已经构建的安装包，不改变签名。相同签名的旧版可覆盖安装，覆盖安装前可先备份重要历史。
