# 文档说明

本目录保存 GalMagan 个人 Android 项目的补充资料。

- 本项目当前只维护 Android 版本，主要测试荣耀 Magic 系列手机上的微信和小红书。
- 历史稳定基线为 `v1.6.0`；当前阶段归档为 `v1.6.4`，后续新功能从归档版本继续开发。
- 真机测试结果以用户实际设备和应用版本为准；本地构建通过不等于所有设备都已验证。

项目的安装、构建、隐私和功能说明见根目录 [README.md](../README.md)。版本变化见 [CHANGELOG.md](../CHANGELOG.md)。
